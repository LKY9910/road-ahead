# 공모전 요약

출처: https://appdevchallenge.auto-hmg.io/ (2026-10-21 확인). 변경 사항은 사이트 공지사항을 기준으로 한다.

## 개요

- **주최:** 현대자동차그룹
- **주제:** 차량 데이터와 기능, 이동 상황을 활용해 운전자와 탑승자에게 새로운 경험을 주는 앱. 출퇴근, 여행, 충전, 주차, 반려동물 동반, 휴식, 업무 등 차를 쓰는 모든 순간이 대상이다.
- **참가:** 1인 참가, **대학생 부문** (예정)

## 1차 심사 기준 (배점 비공개)

1. **차량특화성:** 휴대폰 앱 대비 차량 환경만의 가치가 있는가. 주행·정차 맥락, 차량 기능과 유기적으로 결합되는가.
2. **창의성:** 독창적인가. 운전자·동승자의 불편과 니즈가 명확하고 해결 방식이 분명한가.
3. **기술 활용성:** Pleos Playground의 SDK·API를 핵심 기능과 사용 경험에 적절히 썼는가.
4. **사업성:** 타깃 고객이 명확한가. 사용자 확보와 지속 이용·확대 가능성 (타깃 분석, 예상 MAU, Retention Rate, 확대 계획).

**가산점:** 1차 접수 때 시연 영상(목업·프로토타입·화면 녹화 인정)과 GitHub 저장소(소스 + APK)를 내면 단계별 가산점.
