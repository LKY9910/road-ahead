## 3. 기획서 초안 (02 앱 프로젝트 소개)

### 1. 앱 한 줄 소개

내 차가 갈 방향의 신호가 얼마나 남았는지, 앞길에 살얼음·안개·공사가 있는지를 내비 옆에서 미리 말해 주는 차량용 안내 앱입니다.

### 2. 기획 배경

**교차로**
- 교통사고의 상당수가 교차로에서 납니다. 2015년 기준 국내 교통사고의 44.8%가 교차로에서 났습니다.
- 운전자는 신호가 언제 바뀔지 몰라 노란불에 급히 서거나 무리하게 지나갑니다.
- 도로교통공단이 강릉 교차로 6곳에서 실시간 신호정보 내비 이용 차량과 미이용 차량을 비교했습니다. 이용 차량은 과속이 10%p, 급감속이 14%p, 신호 위반이 6%p 줄었습니다.

**날씨 위험**
- 도로 결빙 사고는 최근 5년간 6,548건 나서 199명이 숨졌습니다. 사고 100건당 사망자가 3.0명으로 전체 교통사고 평균(1.9명)의 1.6배입니다.
- 안개 구간은 앞이 200 m도 안 보이는 순간이 갑자기 찾아옵니다.

**빈 곳**
- 휴대폰 내비(티맵·카카오내비 등)는 일부 지역에서 신호 남은 시간과 살얼음 정보를 보여 줍니다.
- 그러나 차에 들어가는 Pleos Connect 내비와 그 연동 SDK에는 신호 정보도, 날씨에 따른 위험 정보도 없습니다.
- 휴대폰 내비는 차의 상태(와이퍼가 움직이는지, 차가 멈췄는지)를 모릅니다. 그래서 모든 운전자에게 같은 정보를 화면에 띄울 뿐입니다.

**우리가 주목한 순간**
1. 좌회전 차로에서 빨간불에 서서 "언제 바뀌지?" 하며 신호등을 계속 올려다보는 순간
2. 교차로에 다가가는데 신호가 곧 바뀔지 몰라 속도를 정하지 못하는 순간
3. 새벽 고속도로에서 갑자기 안개에 들어가거나, 다리 위 살얼음을 늦게 알아채는 순간

### 3. 앱 주요 기능 및 차량 특화 요소

**주요 기능**

| 기능 | 하는 일 |
|---|---|
| 경로 안내 중 신호 안내 | 내비 경로로 다음 교차로에서 직진·좌회전·유턴 중 어디로 갈지 알아, 그 방향 신호만 골라 알려 줍니다. 빨간불에 서 있으면 "좌회전 신호까지 25초 남았어요", 곧 바뀌면 "곧 좌회전 신호로 바뀌어요". 다가갈 때 신호가 곧 빨간불이 되면 "앞 신호가 곧 빨간불로 바뀌어요. 속도를 줄이세요." |
| 자유 주행 중 빨간불 알림 | 경로가 없을 때는 앞 교차로가 빨간불일 때만 미리 알려 줍니다. |
| 날씨 위험 알림 | 기상청 도로위험기상정보로 고속도로 구간의 살얼음·안개 단계를 받아, 앞길 3 km 안에 있으면 한 번 알려 줍니다. 예: "2km 앞 안개 구간이에요. 앞이 500m도 안 보여요. 속도를 줄이세요." |
| 공사·통제·사고·재난 알림 | 국가교통정보센터의 돌발·재난 정보로 앞길의 공사(막힌 차로), 전면 통제, 사고, 지하차도 침수 등을 알려 줍니다. |

**차량 특화 요소** (휴대폰 앱으로는 할 수 없는 것)
1. **내비 경로와 결합**: Pleos 내비의 경로 안내 상태와 다음 회전 정보를 받아, 내가 실제로 갈 방향의 신호를 고릅니다.
2. **차량 속도로 정차 판단**: 차가 멈췄을 때만 출발 신호까지 남은 시간을 말합니다. 달리는 중에는 감속 안내만 합니다.
3. **차량 상태로 날씨 판단**: 와이퍼나 성에 제거가 켜져 있으면 이미 날씨가 나쁘다고 보고, 평소에는 넘기는 낮은 단계의 위험(관심)까지 알려 줍니다.
4. **내비 음성과 겹치지 않음**: 차의 오디오 재생 상태에서 내비 안내 음성을 감지해, 내비가 말하는 동안에는 기다렸다가 말합니다. 기다리는 사이 쓸모없어진 안내(지나간 교차로, 바뀐 신호)는 버립니다.
5. **운전 중 화면 원칙**: 음성이 주 안내 수단입니다. 화면은 내비 옆 작은 창에 남은 초와 한 줄 안내만 크게 보여 주고, 주행 중에는 버튼을 숨깁니다.

**안전 원칙**
- "통과 가능", "지금 출발"처럼 서두르게 만드는 말은 하지 않습니다. 멈춤·감속·준비 쪽 안내만 합니다.
- 데이터가 3초 넘게 갱신되지 않거나 단위를 확인하지 못하면 남은 시간을 말하지 않습니다.
- 공공 데이터는 참고용임을 첫 실행 때 알립니다.

### 4. 주요 사용 시나리오

**① 출근길 좌회전 대기** (경로 안내 중)
1. 직장인 A씨가 내비로 회사까지 경로 안내를 받으며 달립니다.
2. 다음 교차로에서 좌회전해야 하는데 좌회전 신호가 빨간불입니다. 앱이 "앞 신호 빨간불이에요. 속도를 줄이세요."라고 말합니다.
3. 정지선에 서자 "좌회전 신호까지 25초 남았어요."라고 알려 줍니다. A씨는 신호등을 올려다보지 않고 기다립니다.
4. 신호가 바뀌기 직전 "곧 좌회전 신호로 바뀌어요."라고 알려 줍니다.

**② 퇴근길 자유 주행**
1. 경로 없이 익숙한 길을 달리는 B씨에게, 앞 교차로가 빨간불이면 "앞 신호 빨간불이에요."라고 미리 알려 줍니다.
2. B씨는 브레이크를 일찍, 천천히 밟습니다.

**③ 새벽 고속도로 안개**
1. 새벽에 중부내륙고속도로를 달리는 C씨에게 "2km 앞 안개 구간이에요. 앞이 500m도 안 보여요. 속도를 줄이세요."라고 알려 줍니다.
2. 와이퍼가 켜져 있으면 옅은 안개(관심 단계)도 미리 알려 줍니다.

**④ 겨울 아침 살얼음과 공사**
1. 11월 중순 이후 아침, 다리 구간 살얼음 "주의" 단계를 3 km 앞에서 알려 줍니다.
2. 이어서 앞길 공사로 막힌 차로를 알려 줍니다. 예: "1.2km 앞 공사 구간이에요. 4차로 차단."

### 5. 개발 계획

**구조**
- 판단 로직(`core`)은 차량·안드로이드에 의존하지 않는 모듈로 만들어 단위 테스트로 검증합니다.
- 차량 SDK와 공공 API는 그 앞에 연결합니다.
- 같은 판단 로직에 기록 데이터를 재생하는 시연 모드를 꽂아, 에뮬레이터에서도 장면을 그대로 재현합니다.

**Pleos Connect SDK·API 사용 계획**

| 구분 | 사용 | 용도 |
|---|---|---|
| NaviHelper 3.0.5 | `onNavigationStatus`, `onTBTInfo`, `onRouteStateInfo` | 경로 안내 중인지, 다음 회전 방향과 거리 |
| Vehicle 2.3.2 | 와이퍼 상태, 앞·뒤 성에 제거, 기어 | 날씨 판단, 주차 중 설정 화면 |
| TextToSpeech 3.3.1 | ON_DEVICE 한국어 | 음성 안내(말 시작까지 0.02초 이내 실측) |
| AAOS 차량 속성 | `PERF_VEHICLE_SPEED` | 정차 판정(약 5Hz) |
| Android | 위치, 오디오 재생 상태 콜백 | 진행 방향, 내비 음성 감지 |
| 공공 API | 행정안전부 교통안전 신호등 실시간 정보 | 방향별 신호 색과 남은 시간 |
| 공공 API | 기상청 API허브 도로위험기상정보 | 고속도로 구간별 살얼음·안개 단계(5분 갱신) |
| 공공 API | 국가교통정보센터 돌발상황·재난상황정보 | 공사·통제·사고·침수 등 |

**실측으로 확인한 제약과 대응** (에뮬레이터, 2026-10-28)
- **신호 남은 시간 단위**: 명세(0.01초)와 실제 감소량(0.001초)이 10배 달랐습니다. 앱이 교차로마다 연속 응답으로 단위를 스스로 확인하고, 확인하지 못하면 초를 말하지 않습니다.
- **주행 중 화면**: 일반 화면은 주행 중에 가려졌습니다. 주행 중 사용 가능한 화면으로 선언하고 정보량을 줄였습니다.
- **소리 겹침**: 내비 음성과 우리 음성이 동시에 나왔습니다. 오디오 재생 용도로 내비 음성을 감지해 기다립니다.
- **호출 한도**: 신호 API는 하루 5,000회 한도라서, 앞 1 km 안에 교차로가 있을 때만 2초 간격으로 조회합니다.
- **개인정보**: 위치는 기기 안에서만 씁니다. 외부 API에는 지역 코드, 고속도로 노선 번호, 약 10 km 범위만 보냅니다.

### 6. 기대효과 및 발전 가능성

**사용자 가치**
- 안전: 교차로 감속을 미리 유도하고, 안개·살얼음 구간 진입 전에 경고합니다. 강릉 분석의 과속·급감속·신호 위반 감소가 근거입니다.
- 편의: 신호 대기 중 신호등을 계속 보지 않아도 되고, 출발을 미리 준비할 수 있습니다.
- 운전 집중: 화면 대신 음성으로, 필요한 순간에 한 번만 말합니다.

**타깃 고객**

| 순위 | 고객 | 특징 |
|---|---|---|
| 1차 | 신호 데이터 지역의 출퇴근 운전자 | 같은 길을 매일 반복해서 다니므로 재사용이 잦습니다. 지금 실시간 데이터가 오는 지역은 울산입니다. |
| 2차 | 고속도로 장거리·새벽 운전자 | 안개·살얼음 관측 구간이 있는 12개 노선을 다닙니다. 겨울철에 수요가 큽니다. |
| 3차 | 업무용 차량 운전자 | 법인·화물 차량입니다. 이후 B2B로 확대합니다. |

**MAU 추정 방법** (가정은 제출 전 사용자가 확정)
- 계산식: Pleos Connect 탑재 차량 수 × 앱 설치율 × 월 사용률
- Pleos Connect는 2026년 5월 신차부터 적용되며, 2030년까지 약 2,000만 대에 적용하는 것이 목표입니다.
- 예시(가정)
  - 1년 차: 국내 탑재 50만 대 × 설치율 10% × 월 사용률 60% = 약 3만 MAU
  - 3년 차: 신호 데이터 지역 확대를 반영해 국내 탑재 200만 대 × 15% × 60% = 약 18만 MAU
- Retention: 출퇴근은 매일 반복되는 이용입니다. 가정 목표는 30일 재사용률 40%입니다. 날씨 기능은 겨울철 재방문을 끌어올립니다.

**확대 계획**
1. **신호 데이터 지역 확대**: 지금은 울산에서만 실시간 값이 옵니다. 서울 등 교차로 목록만 있는 지역이 실시간 값을 열면 바로 붙습니다. 지역 코드만 추가하면 됩니다.
2. **기상청 관측망 확대**: 2027년까지 31개 고속도로로 넓어지는 관측망을 그대로 따라갑니다.
3. **해외 확장**: 신호 상태 표기가 국제 표준(SAE J2735)이라 해외 신호 데이터에도 같은 판단 로직을 쓸 수 있습니다.
4. **차량 데이터 활용 고도화**: 외기 온도, 노면 센서 등 차량 신호가 열리면 살얼음 위험을 차 단위로 판단합니다.
5. **순정 내비·클러스터 연동**: 남은 시간을 계기판이나 HUD에 띄웁니다. 기관과 협력하면 운전자 감속 효과 데이터를 지자체에 돌려주는 모델도 가능합니다.
